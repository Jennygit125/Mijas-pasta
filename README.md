# Custom JS Partial Router / SPA Engine ⚡

A lightweight, vanilla JavaScript client-side routing engine built to dynamically draw and swap pages without triggering full-page browser reloads. 

## 💡 The Story Behind This Project
Before diving into heavy frameworks like React, I wanted to understand *how* modern frameworks handle page transitions under the hood. To combat full-page reloads and simulate a seamless Single Page Application (SPA) architecture (very similar to Next.js partial rendering), I built this custom JavaScript engine from scratch to handle dynamic DOM updates and route management natively.

---

## ✨ Key Features
* **Zero Full-Page Reloads:** Intercepts navigation and dynamically renders views on the fly for a lightning-fast user experience.
* **Dynamic DOM Manipulation:** Programmatically injects, clears, and updates page content based on the active route.
* **Vanilla JavaScript Architecture:** Built entirely without frameworks, relying purely on clean, modular ES6+ JavaScript.
* **Lightweight & Fast:** Minimal overhead with zero heavy dependencies.

---

## 🛠️ Tech Stack
* **Languages:** JavaScript (ES6+), HTML5, CSS3
* **Concepts:** Client-side Routing, DOM Manipulation, History API, SPA Architecture
